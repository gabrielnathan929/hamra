# Hamra

NixOS + Home Manager configuration library. Every program is a self-contained toggle module — enable it in your host file and it works.

---

## Quick Start

```bash
# 1. Clone
git clone https://github.com/gabrielnathan929/hamra
cd hamra

# 2. Enter dev shell (has all tools: statix, deadnix, sops, alejandra, etc.)
nix develop

# 3. Generate your host (interactive wizard)
nix run .#cookiecutter

# 4. Build and apply
sudo nixos-rebuild switch --flake .#your-host
```

## Structure

```
hosts/<machine>/           # Per-host config (generated by cookiecutter)
├── configuration.nix      # Import shim
├── hardware-configuration.nix
└── config/
    ├── system.nix         # hostname, user, locale, theme, boot, networking
    ├── hardware.nix       # GPU, audio, bluetooth, touchpad, etc.
    ├── desktop.nix        # compositor, display manager, xdg portal
    ├── programs-core.nix  # core toggles (default=true)
    ├── programs-optionals.nix  # optional toggles (default=false)
    └── home.nix           # Home Manager toggles
modules/
├── nixos/                 # NixOS layer (packages, services, system config)
│   ├── core/              # Base system, assertions, themes, firewall
│   └── programs/
│       ├── core/          # Core programs (default=true)
│       └── optionals/     # Optional programs (default=false)
└── home/                  # Home Manager layer (user config only)
    └── programs/          # Shell, editor, terminal, keybinds
```

**Layer rule:** Package installation → NixOS modules. User config (dotfiles) → Home Manager modules.

## Toggle Families

| Family | Path | Default | Purpose |
|--------|------|---------|---------|
| Core | `hamra.programs.core.<cat>.<name>` | `true` | Base system: boot, firewall, security, recurring utils |
| Optional | `hamra.programs.optionals.<cat>.<name>` | `false` | Personal choice: IDEs, games, media, AI tools |
| Home | `hamra.home.programs.<cat>.<name>` | varies | User-level config (editor, shell, keybinds) |

Categories: `cli/`, `tui/`, `gui/`, `services/`, `media/`, `games/`, `packaging/`.

## Key Commands

| Command | Description |
|---------|-------------|
| `nix fmt .` | Format all Nix files (alejandra) |
| `nix flake check` | Evaluate all hosts + assertions |
| `nix develop` | Dev shell with all tools |
| `nix run .#build-<host>` | Build without applying (`./result`) |
| `nix run .#deploy-<host>` | Full check + `nixos-rebuild switch` |
| `nix run .#cookiecutter` | Generate new host (interactive) |
| `shelf` | List installed/available apps (Nix, mise, Flatpak, webapps) |
| `keys [context]` | Show keybinds (WM, tmux, herdr) |
| `hamra-saves` | Manage game saves (`games.saves` toggle) |

## Apps Outside Nix

| Option | Purpose |
|--------|---------|
| `hamra.mise.tools` | mise tools (via HM `~/.config/mise/config.toml`) |
| `hamra.flatpak.apps` | Flatpak apps via `flatpak-sync` service |
| `hamra.webapps` | Web app wrappers + `.desktop` files |

## Forking for Personal Use

1. Fork the repo
2. Generate your hosts with `cookiecutter` (they go in `hosts/<your-machine>/`)
3. Keep `hosts/` in your fork — **never submitted upstream** (CI blocks PRs touching `hosts/`)
4. Pull library updates from upstream conflict-free
